Disarium Number
A number is said to be Disarium if the sum of it's digits raised to their respective positions is the number itself.
Challenge is to create a function to identify if a number is Disarium or not.
Example input: 75 > 7^1 + 5^2 = 7 * 25 = 32 = False
I chose this quick challenge because it sounded interesting. 

I ended up with 4 versions of the same thing. Each do the same thing but, each is very different. 

First version was just a quick first attempt. Works well enough without issues.
While doing this, I was reading a few blogs about Pythonic coding and keeping things tight and less lines of code = better. 

Second version is my attempt at that. Didn't take too long since the original function is relatively simple enough. 10 lines 
to 3 lines of code with no loss of function isn't too bad. 

Third attempt was my first ever attempt at function recursion. I had no reference point, just my Intro to Programming in Python 
D335 course rolling over it once prior to this. It works but, I wasn't very happy with how it looked and decided to do it again. 

Fourth attempt was an actual recursion without wrapper. This one at the time made me scratch my head but, when it finally came 
together it all just clicked. This is a function that uses itself to keep track of the location of the digit.

I enjoyed this challenge even though it was relatively simple. Was nice to dive into new concepts and see them working. 
This single challenge has fueled my need for more challenging projects.
